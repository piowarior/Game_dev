# 🌊 SIMULATOR BENCANA

### Digital Game-Based Learning untuk Edukasi Mitigasi Bencana di Indonesia

## 📖 Tentang Game

SIMULATOR BENCANA adalah game edukasi berbasis simulasi yang dirancang untuk meningkatkan pemahaman pemain mengenai mitigasi bencana, prosedur penyelamatan, dan pengambilan keputusan dalam situasi darurat.

Game ini menggabungkan:

* Edukasi mitigasi bencana
* Simulasi Search and Rescue (SAR)
* Decision-making strategis
* Resource management
* SOP penyelamatan
* Gameplay berbasis mission & objective

Pemain akan berperan sebagai anggota tim SAR baru yang harus memimpin operasi penyelamatan pada berbagai skenario bencana seperti banjir, gempa bumi, dan tsunami.

---

# 🎮 Konsep Gameplay

## 🧑‍🚒 Main Character (MC)

Pemain berperan sebagai anggota tim SAR baru yang memiliki semangat tinggi namun minim pengalaman lapangan.

Tugas pemain:

* Menerima laporan bencana
* Memilih perlengkapan
* Menentukan strategi
* Mengevakuasi korban
* Mengelola resource
* Mengambil keputusan penting di lapangan

Nama karakter sementara:

* Rafi
* Rina

---

# 🗺️ Struktur Chapter

## Chapter 1 — Banjir 🌊

### Level 1

Evakuasi sekolah yang terendam banjir.

### Level 2

Penanganan banjir bandang di area permukiman dengan arus deras.

---

## Chapter 2 — Gempa Bumi 🌍

### Level 1

Pencarian korban di reruntuhan rumah.

### Level 2

Gempa disertai kebakaran sekunder.

### Level 3

Akses jalan dan jembatan runtuh.

---

## Chapter 3 — Tsunami 🌊

### Level 1

Evakuasi warga pesisir menggunakan sistem peringatan dini.

### Level 2

Pencarian korban pasca tsunami.

---

# 🔄 Gameplay Loop

Setiap level memiliki alur gameplay yang sama:

```text
Mission Brief
↓
Loadout Selection
↓
Transit / Route Selection
↓
Field Operation
↓
Decision Making
↓
Mission Debrief
```

---

# 📡 1. Mission Brief

Pemain menerima laporan mengenai:

* Lokasi bencana
* Jumlah korban
* Kondisi cuaca
* Tingkat bahaya
* Objective utama
* Objective tambahan

UI yang digunakan:

* Peta lokasi
* Informasi korban
* Cuaca
* Estimasi risiko

---

# 🧰 2. Loadout Selection

Pemain memilih perlengkapan sebelum menjalankan misi.

## Contoh Equipment

* Perahu karet
* Life jacket
* Tali evakuasi
* Medkit
* Drone
* Chainsaw
* Selang pemadam

## Sistem Inventory

Game menggunakan:

* Kapasitas maksimal
* Sistem berat item
* Resource terbatas

Pemain harus memilih peralatan yang sesuai dengan kebutuhan misi.

---

# 🚗 3. Transit / Route Selection

Pemain memilih jalur menuju lokasi.

## Contoh:

### Jalur Aman

* Waktu lebih lama
* Risiko rendah

### Shortcut

* Lebih cepat
* Risiko tinggi
* Potensi hazard tambahan

Sistem ini memengaruhi:

* Waktu misi
* Resource
* Outcome level

---

# 🛠️ 4. Field Operation

Tahap utama gameplay.

Pemain melakukan:

* Evakuasi korban
* Triage
* Penyelamatan tim
* Navigasi area berbahaya
* Penggunaan equipment
* Koordinasi NPC

---

# 🚨 Sistem Triage

Korban dibagi menjadi:

| Warna     | Prioritas     |
| --------- | ------------- |
| 🔴 Merah  | Kritis        |
| 🟡 Kuning | Cedera sedang |
| 🟢 Hijau  | Cedera ringan |

Pemain harus menentukan prioritas penyelamatan sesuai SOP.

---

# ⚡ Mini Skill Check

Beberapa aksi menggunakan quick-time event:

* CPR
* Rope handling
* Membuka reruntuhan
* Navigasi arus deras

Keberhasilan memengaruhi:

* Keselamatan korban
* Waktu operasi
* Penilaian akhir

---

# ❗ Decision Making System

Pemain akan dihadapkan pada pilihan strategis.

Contoh:

* Menyelamatkan korban kritis terlebih dahulu
* Mengevakuasi kelompok besar
* Menghemat resource
* Mengambil jalur berisiko

Setiap keputusan akan memengaruhi:

* Jumlah korban selamat
* Resource tersisa
* Nilai bintang
* Narasi level

---

# 📊 Mission Debrief

Setelah level selesai, pemain menerima evaluasi.

## Sistem Penilaian

### ⭐ 1 Star

Objective utama selesai.

### ⭐⭐ 2 Stars

Objective utama selesai + efisiensi baik.

### ⭐⭐⭐ 3 Stars

Semua objective selesai + SOP dipatuhi + resource efisien.

---

# 📈 Statistik Debrief

* Jumlah korban selamat
* Waktu operasi
* Resource digunakan
* SOP compliance
* Kesalahan pemain
* Tips edukatif

Contoh tips:

> “Pasang jangkar sebelum menaiki perahu.”

# 🧠 Event Logic

## Contoh Event

### Inventory

```text
IF player click item
AND inventory weight < max capacity
THEN add item to inventory
```

---

### Triage

```text
IF player interact with victim
THEN assign rescue priority
```

---

### Mission Result

```text
IF main objective completed
THEN add 1 star
```

# 🎨 Visual Style

POV yang digunakan:

* Semi Top-Down
* High Angle Camera
* Depth movement

Gerakan:

* Kiri / kanan → horizontal
* Atas → menjauh kamera
* Bawah → mendekat kamera

Style ini dipilih agar:

* Navigasi lebih nyaman
* Area bencana lebih terlihat
* Gameplay rescue lebih fleksibel
